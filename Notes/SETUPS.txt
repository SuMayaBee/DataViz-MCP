CONNECT DATAVIZ-MCP TO CLAUDE.AI WEB
==========================================

Requirements: cloudflared installed, dataviz-mcp installed via uv


STEP 1 — Install dataviz-mcp (if not already)
-----------------------------------------------------
uv tool install "dataviz-mcp[pydata]"


STEP 2 — Start the MCP server with HTTP transport
--------------------------------------------------
export DATAVIZ_MCP_EXTERNAL_URL=<panel-tunnel-url>   (set after step 4)
pls mcp --transport http --port 8001


STEP 3 — Open two more terminals and run these tunnels
------------------------------------------------------
Terminal 2 (MCP server tunnel):
  cloudflared tunnel --url http://localhost:8001

Terminal 3 (Panel server tunnel):
  cloudflared tunnel --url http://localhost:5077

Each gives you a https://*.trycloudflare.com URL.


STEP 4 — Set the external URL and restart MCP
----------------------------------------------
Stop the pls mcp from Step 2 (Ctrl+C), then:

  export DATAVIZ_MCP_EXTERNAL_URL=<url from Terminal 3>
  pls mcp --transport http --port 8001


STEP 5 — Add to claude.ai
--------------------------
1. Go to claude.ai → Settings → Connectors → Add custom connector
2. Name: dataviz-mcp
3. URL: <url from Terminal 2>/mcp      ← note the /mcp at the end
4. Hit Add

You should see 3 tools: show (Interactive), list_packages, validate


STEP 6 — Test it
-----------------
Start a new chat and ask:
  "Show me a simple sine wave plot using hvplot"

First use of each tool will ask for approval — click Allow.


NOTES
-----
- Tunnel URLs change every time you restart cloudflared — re-add the connector each session
- The /mcp path is required for streamable-http transport
- show renders as an MCP App (interactive panel) directly in the chat
- list_packages and validate are plain tools, work without the external URL setup


==============================================================================
CONNECT LOCAL REPO (DEV) TO CLAUDE.AI WEB
==============================================================================

Use this setup when you are hacking on the dataviz-mcp source code and
want claude.ai to talk to your in-repo build instead of the installed tool.

Requirements: cloudflared installed, pixi installed, repo cloned

------------------------------------------------------------------------------
STEP 1 — Clone and install in editable mode
------------------------------------------------------------------------------
  git clone https://github.com/<your-fork>/dataviz-mcp.git
  cd dataviz-mcp
  pixi install
  pixi run postinstall          # installs the package as editable (pip install -e .)

  Alternative (uv):
    uv venv && source .venv/bin/activate
    uv pip install -e ".[dev]"

  Verify the CLI resolves to your local source:
    which pls                   # should point inside .venv or pixi env
    pls --version


------------------------------------------------------------------------------
STEP 2 — Activate your environment (do this in every new terminal)
------------------------------------------------------------------------------
  pixi (no activation needed — prefix every command with `pixi run`):
    pixi run pls --version      # verify

  uv venv:
    source .venv/bin/activate   # Linux/macOS
    .venv\Scripts\activate      # Windows
    pls --version               # verify


------------------------------------------------------------------------------
STEP 3 — Start the MCP server with HTTP transport (leave EXTERNAL_URL unset for now)
------------------------------------------------------------------------------
  pixi:   pixi run pls mcp --transport http --port 8001
  uv:     pls mcp --transport http --port 8001


------------------------------------------------------------------------------
STEP 4 — Open two more terminals and start Cloudflare tunnels
------------------------------------------------------------------------------
  Terminal 2 — MCP server tunnel:
    cloudflared tunnel --url http://localhost:8001

  Terminal 3 — Panel server tunnel:
    cloudflared tunnel --url http://localhost:5077

  Each command prints a unique https://*.trycloudflare.com URL.
  Copy both URLs.


------------------------------------------------------------------------------
STEP 5 — Restart MCP with the Panel tunnel URL wired in
------------------------------------------------------------------------------
  Stop the server from Step 3 (Ctrl+C), then:

    export DATAVIZ_MCP_EXTERNAL_URL=<URL from Terminal 3>
    pixi run pls mcp --transport http --port 8001

  This makes every iframe URL the server returns use your public tunnel address
  instead of localhost, so claude.ai can load the visualisation.


------------------------------------------------------------------------------
STEP 6 — Register as a custom connector in claude.ai
------------------------------------------------------------------------------
  1. Go to claude.ai → Settings → Connectors → Add custom connector
  2. Name:  dataviz-mcp (local dev)
  3. URL:   <URL from Terminal 2>/mcp        ← /mcp suffix is required
  4. Click Add

  You should see the tools: show (Interactive), list_packages, validate


------------------------------------------------------------------------------
STEP 7 — Test a round-trip
------------------------------------------------------------------------------
  Start a new chat and try:
    "Show me a sine wave plot using hvplot"

  Approve the tool on first use.  The visualisation should appear as a live
  Panel iframe inside the chat window.


------------------------------------------------------------------------------
STEP 8 — Iterate on the source code
------------------------------------------------------------------------------
  Edit files under src/dataviz_mcp/.
  Changes to most files take effect immediately (editable install).
  If you edit CLI entry-points or pyproject.toml re-run:
    pixi run postinstall

  Restart `pls mcp` and `pls serve` to pick up changes that affect server
  startup (endpoints.py, app.py, config.py, manager.py).


------------------------------------------------------------------------------
NOTES
------------------------------------------------------------------------------
- Tunnel URLs are ephemeral — they change every time cloudflared restarts.
  Update DATAVIZ_MCP_EXTERNAL_URL and re-add the connector each session.
- The /mcp path is required for streamable-http transport (FastMCP default).
- Run tests before pushing:  pixi run test
- Lint before pushing:       pixi run lint


==============================================================================
CONNECT TO CLAUDE DESKTOP
==============================================================================

No tunneling needed — Claude Desktop runs on the same machine, so localhost
URLs work directly.  MCP uses stdio transport (the default).

Config file location:
  macOS:   ~/Library/Application Support/Claude/claude_desktop_config.json
  Windows: %APPDATA%\Claude\claude_desktop_config.json
  Linux:   ~/.config/Claude/claude_desktop_config.json


------------------------------------------------------------------------------
OPTION A — Hosted package (installed via uv tool or pipx)
------------------------------------------------------------------------------
STEP 1 — Install
  uv tool install "dataviz-mcp[pydata]"

STEP 2 — Add to claude_desktop_config.json
  {
    "mcpServers": {
      "dataviz-mcp": {
        "command": "pls",
        "args": ["mcp"]
      }
    }
  }

STEP 3 — Restart Claude Desktop
  Quit and reopen the app.  The Panel server starts automatically on first use.

STEP 4 — Test
  In any chat: "Show me a simple sine wave using hvplot"
  Approve the tool on first use — a browser tab opens with the live plot.


------------------------------------------------------------------------------
OPTION B — Local repo (editable install for development)
------------------------------------------------------------------------------
STEP 1 — Clone and install (same as the claude.ai local repo setup above)
  git clone https://github.com/<your-fork>/dataviz-mcp.git
  cd dataviz-mcp
  pixi install && pixi run postinstall

STEP 2 — Add to claude_desktop_config.json

  {
    "mcpServers": {
      "dataviz-mcp": {
        "command": "/home/sumayabee/Desktop/dataviz-mcp/.venv/bin/pls",
        "args": ["mcp"]
      }
    }
  }

STEP 3 — Restart Claude Desktop
  Quit and reopen.  Claude Desktop spawns the MCP process from the config above.

STEP 4 — Test
  In any chat: "Show me a simple sine wave using hvplot"

STEP 5 — Iterate
  Edit src/dataviz_mcp/ freely.  To pick up changes restart Claude Desktop
  (it re-spawns the MCP process) or kill and re-spawn pls manually.


------------------------------------------------------------------------------
NOTES
------------------------------------------------------------------------------
- No env vars needed for Claude Desktop — Panel runs on localhost:5077 and
  Claude Desktop opens the URL in your local browser, so no external URL is required.
- To pass env vars (e.g. custom port), add an "env" key to the config block:
    "env": { "DATAVIZ_MCP_PORT": "9999" }
- If pls is not on PATH for Claude Desktop, use the absolute binary path instead.

==============================================================================

Uses stdio transport, same as Claude Desktop.  No tunneling needed.
Requires GitHub Copilot Chat extension (v0.22+).

Config file: .vscode/mcp.json  (project-level, create if it doesn't exist)
Global alternative: add under "mcp.servers" in VS Code user settings.json


------------------------------------------------------------------------------
OPTION A — Hosted package
------------------------------------------------------------------------------
STEP 1 — Install
  uv tool install "dataviz-mcp[pydata]"

STEP 2 — Create/edit .vscode/mcp.json
  {
    "servers": {
      "dataviz-mcp": {
        "type": "stdio",
        "command": "pls",
        "args": ["mcp"]

    }
  }

STEP 3 — Start the server
  Command Palette → "MCP: List Servers" → Start dataviz-mcp

==============================================================================
CONNECT TO CLAUDE CODE (CLI)
==============================================================================

Uses stdio transport.  No config file to edit — one command registers the server.
No tunneling or external URL needed.


------------------------------------------------------------------------------
OPTION A — Hosted package
------------------------------------------------------------------------------
STEP 1 — Install
  uv tool install "dataviz-mcp[pydata]"

STEP 2 — Register the MCP server
  claude mcp add dataviz-mcp -- pls mcp

STEP 3 — Test
  Start a new session: claude
  Then ask: "List your available MCP tools."
  You should see show, validate, and list_packages.

STEP 4 — Try it
  "Show me a simple sine wave using hvplot. Use the show tool."
  Opens a live URL at http://localhost:5077/view?id=...


------------------------------------------------------------------------------
OPTION B — Local repo
------------------------------------------------------------------------------
STEP 1 — Activate the venv and register using the absolute binary path
  source /home/sumayabee/Desktop/dataviz-mcp/.venv/bin/activate
  claude mcp add dataviz-mcp -- /home/sumayabee/Desktop/dataviz-mcp/.venv/bin/pls mcp

  Note: using the absolute path ensures Claude Code spawns the local build,
  not any globally installed pls.

STEP 2 — Test
  Start a new session from the repo directory:
    cd /home/sumayabee/Desktop/dataviz-mcp && claude
  Then ask: "List your available MCP tools."
  You should see show, validate, and list_packages.

STEP 3 — Try it
  "Show me a simple sine wave using hvplot. Use the show tool."

STEP 4 — Iterate
  Edit src/dataviz_mcp/ freely.  Restart the MCP server to pick up changes:
    claude mcp remove dataviz-mcp
    claude mcp add dataviz-mcp -- /home/sumayabee/Desktop/dataviz-mcp/.venv/bin/pls mcp


------------------------------------------------------------------------------
NOTES
------------------------------------------------------------------------------
- claude mcp add writes to ~/.claude.json (scoped to the project directory).
- To see all registered servers: claude mcp list
- To remove:  claude mcp remove dataviz-mcp
- No external URL needed — browser opens localhost:5077 directly.
